# nuce-slides

日本大学 経済学部 多鹿の講義スライドです。

## 閲覧

公開ページ：[https://ttajika.github.io/nuce-slides/](https://ttajika.github.io/nuce-slides/)

## PDF の再生成

```bash
tools/gen-pdf.sh 2026   # 2026 の全スライド → 2026/pdf/
```

詳細は [tools/README.md](tools/README.md) を参照。
