1. スライド操作・ナビゲーション

基本操作

操作方法
次のスライド→ または Space、ツールバー ▶
前のスライド←、ツールバー ◀
最初のスライドへツールバー ⏮
最後のスライドへツールバー ⏭
セクションへジャンプツールバー中央のドロップダウンで選択

タッチ操作（タブレット・スマートフォン）

  • 左スワイプ：次のスライド
  • 右スワイプ：前のスライド
描画モード中はスワイプによるスライド移動は無効になります。

ページ表示

ツールバー右側に現在のスライド番号と総数が表示されます（例：12 / 85）。フィルタ適用中はフィルタ後の番号も表示されます。

2. 描画・書き込みツール

スライド上に直接書き込みができます。ツールバーの ✏️ ボタンまたは D キーで描画モードの ON/OFF を切り替えます。

描画ツール

ツールキー説明
ペンP通常の書き込み（不透明）
ハイライトH半透明（30%）の太線マーカー
消しゴムE触れたストロークを削除
ポインタL赤い光点を表示（書き込みなし）

色の選択

描画ツールバーに5色のカラーパレットが表示されます。

  • 赤（デフォルト）
  • シアン
  • 黄
  • 黒
  • 青

線の太さ

スライダーで 1〜16 の範囲で調整できます。ハイライトは設定値の3倍の太さで描画されます。

取り消し・全消去

操作方法
直前のストロークを取り消しCtrl+Z（Mac: ⌘+Z）またはツールバー ↩️
現在のスライドの全ストローク消去ツールバー 🗑️
書き込みはスライドごとに保存され、スライドを移動しても保持されます。

3. 板書スペース

スライドとは別の白紙キャンバスを開いてメモや計算ができます。

  • 開く/閉じる：B キーまたはツールバーの 📋 ボタン
  • 閉じる：Esc、✕ ボタン、またはポップアップ外をクリック

板書スペースのツール

  • 4色のカラーパレット（ 赤 ／ 青 ／ 黒 ／ 緑）
  • 線の太さスライダー
  • 消しゴム（🧹）
  • 取り消し（↩️）・全消去（🗑️）
板書はスライドごとに独立して保存されます。

4. 穴埋め（Phantom テキスト）

スライド内の一部のテキストが薄い背景色で隠されています。

  • 個別に表示：隠されたテキスト部分をクリック
  • すべて表示：R キーで現在のスライドの穴埋めを一括表示

5. ノート機能

各スライドにテキストメモを残せます。

  • 開く/閉じる：ツールバーの 📝 ボタンまたは N キー
  • 画面右側にノートパネルが表示されます
  • 入力内容はスライドごとに自動保存されます
  • クリアボタンで現在のスライドのノートを削除
ノートはブラウザのローカルストレージに保存されます。ブラウザのデータを消去すると失われるため、大切なメモは「データの書き出し」機能でバックアップしてください。

6. 理解度チェック・ブックマーク

理解度チェック

ツールバーの 📊 ボタンで表示を切り替えます。各スライドに3段階の理解度を設定できます。

ボタン意味背景色
✅ わかった理解できた緑
🤔 あやしい少し不安黄
❌ わからない理解できていない赤

同じボタンをもう一度クリックすると解除されます。

ブックマーク

ツールバーの ⭐ ボタンで、現在のスライドをブックマークに追加/解除できます。

7. フィルタ機能

ツールバーの 🔍 ボタンでフィルタバーを表示し、条件に合うスライドだけを表示できます。

フィルタ表示されるスライド
すべて全スライド
⭐ ブックマークブックマーク済みのスライド
✅ わかった理解度「わかった」のスライド
🤔 あやしい理解度「あやしい」のスライド
❌ わからない理解度「わからない」のスライド
⬜ 未チェック理解度未設定のスライド

フィルタ適用中は、← → キーで該当スライド間をジャンプします。

8. 図の拡大・動画再生・QRコード

図の拡大（ライトボックス）

スライド内の図（SVG）をクリックすると全画面で拡大表示されます。Esc キーまたは図の外側をクリックで閉じます。

動画再生

スライド内の「▶ 動画を再生」ボタンをクリックするとオーバーレイで動画が再生されます。Esc キーまたは外側クリックで閉じます。

QRコード

リンク横の 📱 アイコンをクリックするとQRコードが表示されます。スマートフォンで読み取ってリンク先にアクセスできます。

9. データの保存・書き出し・読み込み

自動保存

ノート・描画・板書・理解度・ブックマークはすべてブラウザのローカルストレージに自動保存されます。次回アクセス時に復元されます。

ローカルストレージはブラウザの閲覧データ消去・シークレットモードの終了・ブラウザの変更などで失われます。大切なデータは定期的に下記の「データ書き出し」機能でバックアップするか、クラウド保存にログインしてください。

データ書き出し（エクスポート）

ツールバーの 💾 ボタンで、すべてのデータを JSON ファイルとしてダウンロードできます。

  • ファイル名例：math_econ_study_2026-04-15.json
  • 含まれるデータ：ノート、描画、板書、理解度、ブックマーク

データ読み込み（インポート）

ツールバーの 📂 ボタンで、書き出した JSON ファイルを読み込めます。既存のデータとマージされます。

10. クラウド保存（ログインして端末間で同期）

ログインすると、書き込みやノートがクラウド上に自動保存され、別の端末・別のブラウザからでも同じ内容を続きから使えます。ログインしなくてもスライドはこれまで通り使えます（その場合はブラウザのローカル保存のみ）。

ツールバー右端に 🔑 ボタンが表示されている科目で利用できます。表示されていない科目はクラウド保存に未対応です。

アカウントの作成とログイン

  1. ツールバー右端の 🔑 ボタンをクリックします。
  2. ID（学籍番号など）とパスワード（6文字以上）を入力します。
  3. 初回は「新規登録」、2回目以降は「ログイン」を押します。
氏名や本物のメールアドレスは入力しないでください。ID は自由に決められます（内部的にダミーのアドレス形式に変換して扱うため、個人情報は保存されません）。
パスワードを忘れた場合は自分では再設定できません。教員に連絡してリセットしてもらってください。

ログイン中の表示

  • 🔑 ボタンが緑色になります。ボタンにマウスを乗せるとログイン中の ID が表示されます。
  • ボタンの横に同期状態が表示されます。
表示意味
同期中…クラウドと通信しています
✓ 同期済み最新の内容が保存されています
⚠ 同期エラー通信に失敗しました（ネットワークを確認してください。データはローカルには残っています）

同期されるデータ

  • ノート
  • スライドへの書き込み（描画）
  • 板書スペースの内容
  • 理解度チェック
  • ブックマーク
  • 最後に開いていたスライド番号

手書きの座標は画面サイズに依存しない形式に変換して保存されるため、PC とタブレットのように画面の大きさが違う端末の間でも位置がずれません。

同期のタイミング

場面動作
書き込み・ノート入力などをしたとき約2秒後に自動でクラウドへ保存
ログインしたとき／ページを開いたときクラウド側が新しければ自動で取り込み、そうでなければ手元の内容をアップロード
「いま同期する」ボタンクラウドの内容を強制的に取り込み
「いま同期する」は上書きです。クラウド側の内容で現在の端末のデータが置き換えられます。この端末でしか書いていない内容がある場合は、先に 💾 で書き出してから実行してください。

データはページ（科目）ごとに分かれています

同期は科目ごとに独立しています。経済数学 II の書き込みが基礎ミクロ経済学に混ざることはありません。

ログアウト

🔑 ボタン →「ログアウト」で解除できます。共用のパソコンを使った場合は、必ずログアウトしてください。

複数端末で同時に編集した場合の注意：同期は「あとから保存された内容で上書き」する方式で、2つの端末の書き込みを混ぜ合わせる（マージする）わけではありません。1台で書き込んで同期が済んでから次の端末を開く、という順番で使ってください。

ログインしない場合

これまで通り、データはブラウザのローカルストレージにのみ保存されます。💾 による書き出しは、ログインの有無にかかわらずいつでも利用できます。

11. 印刷用表示（ハンドアウト）

画面下部の「📄 印刷用表示」ボタンをクリックすると、全スライドを一覧表示する印刷用レイアウトに切り替わります。

  • 各スライドの下にメモ書き用の余白が表示されます
  • 「改ページ区切り」トグルで、スライドごとの改ページを ON/OFF できます
  • 穴埋めテキストは透明表示になります
  • QRコードは自動的に展開表示されます
  • タイトルスライドと Note フレームは印刷対象から除かれます
  • もう一度ボタンをクリックするとスライドモードに戻ります

PDF として保存する

印刷用表示のまま、ブラウザの印刷機能で PDF ファイルとして保存できます。

  1. 「📄 印刷用表示」に切り替えます。数式の描画が終わるまで数秒待ってください。
  2. 1枚ずつページを分けたい場合は「改ページ区切り: ON」にします（スライドがページの途中で分断されなくなります）。
  3. Ctrl+P（Mac: ⌘+P）で印刷ダイアログを開きます。
  4. 出力先を PDF にして保存します。
ブラウザ操作
Chrome / Edge「送信先」で PDF に保存 を選び「保存」
Safari（Mac）ダイアログ左下の PDF ▾ →「PDF として保存」
Firefox「プリンター」で Microsoft Print to PDF / PDF に保存 を選択
iPad / iPhone共有ボタン →「プリント」→ プレビューをピンチで拡大 → 共有から「ファイルに保存」

きれいに出力するための設定

  • 背景のグラフィックを ON：Chrome では「詳細設定」→「背景のグラフィック」にチェックを入れないと、色付きの枠や強調の背景色が印刷されません。
  • 用紙は A4・縦が標準です。図を大きく見たい場合は横向きにします。
  • 余白は「なし」または「最小」にすると、スライドが大きく収まります。
  • 1ページに収まりきらないときは倍率（拡大縮小）を 80〜90% 程度に下げます。
手書きの書き込み・ノートは PDF には含まれません。印刷用表示は書き込み前の白紙ハンドアウトとして出力されます（メモ欄は空欄のままです）。書き込んだ内容を残したい場合は 💾 でのデータ書き出し、または クラウド保存を使ってください。
穴埋め部分は透明のまま出力されるので、印刷した PDF は空欄プリントとして自習に使えます。答え合わせは画面側でクリックして確認してください。

13. 学生へのおすすめの使い方

授業中

  • 穴埋めを活用する：穴埋め部分をすぐにクリックせず、まず自分で考えてから答えを確認しましょう。
  • 描画ツールで書き込む：ペンやハイライトを使って、スライド上に直接メモや補足を書き込みましょう。板書の内容を写すのにも便利です。
  • 板書スペースを使う：B キーで白紙キャンバスを開いて、計算の途中式や自分なりの整理を書き留めましょう。
  • ノートを残す：N キーでノートパネルを開き、先生の口頭での補足や自分の疑問点をテキストで記録しましょう。

授業後の復習

  • 理解度チェックをつける：スライドを1枚ずつ見直しながら「✅ わかった」「🤔 あやしい」「❌ わからない」を設定しましょう。自分の理解状況を可視化できます。
  • フィルタで苦手箇所を集中復習：フィルタ機能で「🤔 あやしい」「❌ わからない」だけを表示し、重点的に復習しましょう。理解できたら「✅ わかった」に更新します。
  • ブックマークで重要スライドを管理：試験に出そうなスライドや重要な定義・定理のスライドに ⭐ をつけておくと、後から素早くアクセスできます。

試験前

  • ブックマーク＋フィルタで総復習：⭐ ブックマークのフィルタを使い、重要スライドだけを通しで確認しましょう。
  • 穴埋めで知識を確認：穴埋めテキストを隠した状態で答えを思い出してからクリックし、定着度をチェックしましょう。
  • 印刷用表示で紙に出す：「📄 印刷用表示」でハンドアウトを作成し、書き込み用の余白付きで印刷すると、紙での復習にも活用できます。PDF として保存すれば、タブレットのノートアプリに取り込んで書き込むこともできます。

データのバックアップ

  • まずログインする：🔑 ボタンからログインしておけば、書き込み・ノート・理解度が自動でクラウドに保存され、教室のパソコンと自宅のパソコン、タブレットのいずれからでも同じ状態で続きができます。→ 10. クラウド保存
  • 定期的にエクスポート：ログインしない場合、ノートや描画などのデータはブラウザにのみ保存されているため、ブラウザのデータ消去で失われます。💾 ボタンで定期的に JSON ファイルを書き出しておきましょう。
  • 別のブラウザ・端末への移行：書き出した JSON ファイルを 📂 ボタンで読み込めば、別の環境でも同じデータで学習を続けられます。
